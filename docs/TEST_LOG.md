## 2026-11-20 · 非中文透传改造

### 背景

发现"只要句子含一个汉字，整句（含英文、数字、权重、`<lora:>`）都会进模型"，
导致：

- `abc` 被模型判成负向
- `(masterpiece:1.2)` 被标点切碎成 `masterpiece:1.2)`
- `不要 watermark` 里的 watermark 被"自动补回"又加进正向

### 改动（全部在节点 Python 层，模型未动）

| 函数 | 层 | 改动 |
|---|---|---|
| `split_verbatim()` | 预处理（新增） | 逐字符扫描，按分句把中文与非中文分开；只有 `，,。；;、！？!?` 是分句符，`.` `:` `()` 不算 |
| `translate()` | 后处理 | 合并透传片段（正向/负向按分句否定判断） |
| 自动补回 | 后处理 | 已在负向中的 token 不再补回正向 |

### 验证

| 输入 | 期望 | 结果 |
|---|---|---|
| 花海 abc | abc 原样正向 | ✅ |
| 少女站在花海 `<lora:lilyww_v1:0.8>` | LoRA 标签完整 | ✅ |
| 少女微笑, (masterpiece:1.2), 1girl | 权重括号不被切 | ✅ |
| 不要 watermark，樱花 | 樱花正向，watermark 负向 | ✅ |
| a girl in flower field, smile | 整句透传 | ✅ |

### 未解决

- `去掉文字和签名` 这类并列否定，模型仍会整条丢弃（待做拆分）
- 长短语匹配（`双手交叠在胸前`）模糊匹配覆盖不到

原始输出：本轮未单独落盘，见节点 info 输出。

## 2026-11-20 · Qwen 单项能力测试（排除词库）

### 方法

直接调用 `ask_model()`，只看模型输出的中文短语，不经过词库。

24 个用例，五类：分词粒度 / 语义同义 / 否定识别 / 隐含推断 / 格式边界。

### 结果

| 类别 | 通过 | 结论 |
|---|---|---|
| 分词粒度 | 5/5 | 优秀，虚词自动剥离 |
| 隐含推断 | 5/5 | 优秀，保留场景关系 |
| 格式边界 | 4/4 | 优秀，JSON 100% 合法 |
| 语义同义 | 2/5 | 弱，不做同义归一 |
| 否定识别 | 3/5 | 弱，并列否定会丢词 |

```
总通过 19/24（79%）
平均耗时 0.8s
JSON 合法 24/24
```

### 典型正确

```
穿白裙的少女在窗边看书 → 穿白裙的少女 / 窗边 / 看书
坐在咖啡馆靠窗的位置   → 坐在咖啡馆 / 靠窗的位置
一只白猫趴在书桌上     → 白猫 / 趴在书桌
未加标点的 80 字长句   → 少女 / 薄雾 / 木栈道 / 百合花 / 黄昏 / 轮廓光
```

### 典型失败

| 输入 | 输出 | 问题 |
|---|---|---|
| 她有点不好意思地低下头 | 不好意思 / 低下头 | 不会归一成"害羞/低头" |
| 女孩脸上泛起红晕 | 脸上 / 泛起红晕 | 不会归一成"脸红" |
| 去掉文字和签名 | 空 | 并列否定整条丢弃 |
| 别让头发遮住眼睛 | 遮住 | 只剩动词 |

### 结论

> Qwen 1.5B 是合格的分词器，不是语义映射器。
> "同义归一"应由词库（别名）承担，不该指望模型。

原始数据：`E:\AI\qwen_test.json`、`E:\AI\qwen_test.log`

## 2026-11-20 · 长文本测试

### 方法

10 个样本，长度 4 ~ 403 字，走完整链路（模型 + 词库），记录耗时、标签数、未收录数。

### 结果

| 编号 | 类型 | 字数 | 耗时 | 正向标签 | 未收录 |
|---|---|---|---|---|---|
| T01 | 超短 | 4 | 6.2s* | 4 | 0 |
| T02 | 短 | 11 | 1.0s | 5 | 0 |
| T03 | 中 | 22 | 2.0s | 7 | 0 |
| T04 | 中长 | 38 | 2.0s | 11 | 0 |
| T05 | 长 | 75 | 2.0s | 10 | 4 |
| T06 | 长篇 | 191 | 2.0s | 6 | 8 |
| T07 | 长口语 | 143 | 2.0s | 10 | 8 |
| T08 | 超长 | 403 | 3.0s | 9 | 12 |
| T09 | 极长重复 | 251 | 2.0s | 8 | 0 |
| T10 | 中英混合 | 187 | 2.0s | 12 | 0 |

\* 含模型加载。

### 关键发现

1. **耗时与长度无关**：4 字和 403 字都是 1-3 秒。
2. **标签数不增反降**：38 字出 11 个，191 字只出 6 个（模型倾向概括）。
3. **否定词在长文本里会丢**：T06/T08 模型返回 negative = 0，靠 `强制负向` 兜回。
4. **分段输入命中率更高**：

| 文本 | 整段命中率 | 分段命中率 |
|---|---|---|
| T06 | 27% → 补词后 100% | 37% → 79% |
| T08 | 40% → 95% | 49% → 77% |

### 归因（重要）

```
细节丢失 = 10% 模型概括 + 20% 短语过长匹配不上 + 70% 词库缺词
```

**补词库是主要手段，换模型只解决那 10%。**

### 补词后

新增 29 条（原野、花冠、黑纱、天空、云层、山峦、湖泊、花瓣、尘埃、影子、长裙、
白色百合花、暖色调、背景虚化、蕾丝装饰、黑色长靴、头发、橙色、紫色、女孩子、
角落、窗户、桌子、书架、暖和、怀旧、哥特风格长裙、对比度适中、光斑）。

词库：351 → 380 条，长文本整段命中率 27% → 95~100%。

原始数据：`E:\AI\longtext\result.csv`、`E:\AI\longtext\full.txt`
